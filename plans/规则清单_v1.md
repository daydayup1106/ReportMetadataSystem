# 规则清单 v1

## 1. 规则原则

- 规则优先于 AI
- 确定性规则直接判定
- AI 规则只产生 `warning` 或 `review`
- AI 结果默认不能直接落库
- 每条规则必须有：编号、对象、触发条件、严重级别、提示文案、修复建议

严重级别：

- `error`：必须修复，否则不能确认入库
- `warning`：建议修复，可人工确认后入库
- `info`：提示类问题
- `review`：需要人工复核，通常来自 AI 检查

## 2. 结构完整性规则

| 编号 | 对象 | 级别 | 检查项 |
|---|---|---|---|
| STR-001 | Report | error | `reportId` 必填 |
| STR-002 | Report | error | `reportName` 必填 |
| STR-003 | Report | error | 至少存在一个 `column` |
| STR-004 | Column | error | `columnName` 必填 |
| STR-005 | Column | error | `originalColumnName` 必填 |
| STR-006 | Parameter | error | `parameterName` 必填 |
| STR-007 | Parameter | warning | `originalColumnName` 不能为空 |
| STR-008 | Role | error | `environment` 必须存在 |
| STR-009 | Config | error | `reportId` 必须存在 |
| STR-010 | UI Settings | error | `reportId` 必须存在 |

## 3. 格式规范规则

| 编号 | 对象 | 级别 | 检查项 |
|---|---|---|---|
| FMT-001 | Report | error | `reportId` 仅允许字母、数字、下划线、连字符 |
| FMT-002 | Report | error | `reportFormatSpecId` 必须符合指定 ID 格式 |
| FMT-003 | Report | error | `reportDomainId` 必须符合指定 ID 格式 |
| FMT-004 | Role | error | `environment` 只能是 `dev/sit/uat/prod` |
| FMT-005 | Column | warning | `dataType` 为空或不在允许集合中 |
| FMT-006 | Parameter | warning | `parameterType` 为空或不在允许集合中 |
| FMT-007 | All | warning | 同一报表内命名风格不一致 |
| FMT-008 | All | warning | 字段或参数名过长、含无意义缩写或非法字符 |

## 4. 唯一性与冲突规则

| 编号 | 对象 | 级别 | 检查项 |
|---|---|---|---|
| UNI-001 | Report | error | `reportId` 全局唯一 |
| UNI-002 | Column | error | 同一报表下 `columnName` 不能重复 |
| UNI-003 | Column | error | 同一报表下 `originalColumnName` 不能重复 |
| UNI-004 | Parameter | error | 同一报表下 `parameterName` 不能重复 |
| UNI-005 | Role | error | 同一报表下 `reportId + environment` 唯一 |

## 5. 一致性规则

| 编号 | 对象 | 级别 | 检查项 |
|---|---|---|---|
| CNS-001 | Parameter | error | `originalColumnName` 必须能在 columns 中找到 |
| CNS-002 | UI Settings | error | UI columns 必须能映射到 report columns |
| CNS-003 | Config | warning | `config.reportName` 应与 `report.reportName` 一致 |
| CNS-004 | Role | warning | `role.reportName` 应与 `report.reportName` 一致 |
| CNS-005 | All | warning | `reportType`、`categories`、UI tabs 存在明显不一致 |
| CNS-006 | Export | error | 导出包内对象主键不一致 |
| CNS-007 | Version | warning | 新版本删除关键字段但未标记变更说明 |

## 6. 语义与治理规则

| 编号 | 对象 | 级别 | 检查项 |
|---|---|---|---|
| GOV-001 | Report | warning | `reportDescription` 缺失或过短 |
| GOV-002 | Column | warning | `columnDescription` 缺失或过短 |
| GOV-003 | Column | review | description 只是重复列名，无有效语义 |
| GOV-004 | Column | review | 字段名与数据类型明显不匹配 |
| GOV-005 | Parameter | review | 参数名语义不清，无法判断用途 |
| GOV-006 | Report | review | `reportName`、`reportType`、字段集合存在明显语义冲突 |
| GOV-007 | Monetary Fields | review | 金额类字段缺少币种或金额语义说明 |
| GOV-008 | Time Fields | review | 时间类字段被标成普通字符串且无格式说明 |

说明：

- `review` 规则可以使用 AI 辅助
- AI 只给出风险和建议，不直接生成正式内容

## 7. 可运维性规则

| 编号 | 对象 | 级别 | 检查项 |
|---|---|---|---|
| OPS-001 | Report | warning | 缺少 `updatedBy` |
| OPS-002 | Report | warning | 缺少 `updatedAt` |
| OPS-003 | Import | warning | 缺少导入来源或导入批次号 |
| OPS-004 | Version | warning | 未生成版本快照 |
| OPS-005 | Audit | warning | 修复动作未记录操作人和时间 |
| OPS-006 | Export | warning | 导出包缺少完整对象集合 |

## 8. 入库策略

- 存在 `error`：禁止确认入库
- 仅存在 `warning/info/review`：允许人工确认后入库
- AI 触发的 `review` 默认不能自动关闭
- 所有修复动作必须记录审计日志

## 9. V1 不做的规则

- 不做跨系统真实数据对账
- 不做自动业务含义补全
- 不做自动生成正式描述
- 不做自动审批规则
- 不做自定义脚本规则执行
