# 业务边界说明

## 1. 产品定位

本项目不是完整报表平台。

本项目定位为：

**报表元数据治理与智能检索平台**

系统只处理报表的元数据、配置、权限、版本、治理和检索问题，不处理真实报表数据执行。

## 2. 系统负责什么

- 导入 Excel/JSON 形式的报表元数据
- 解析并标准化存储 `report / columns / parameters / roles / config / ui settings`
- 对元数据执行规则校验
- 输出问题清单、严重级别、修复建议
- 支持人工确认、修复、复核
- 支持元数据检索、参数检索、配置检索、角色检索
- 支持报表对比、版本对比、环境差异对比
- 支持 Chat/RAG 查询并返回证据引用
- 支持导出完整元数据包
- 记录导入、修复、导出、AI 查询等操作日志

## 3. 系统不负责什么

- 不执行真实报表
- 不连接业务数据库跑报表查询
- 不做报表调度
- 不做邮件推送
- 不做模板设计器
- 不做自动审批
- 不做多租户 SaaS
- 不让 AI 自动编造 description 并直接落库
- 不让 AI 自动修改正式配置

## 4. AI 的职责边界

AI 只做以下事情：

- 智能检查
- 风险提示
- 检索归纳
- 证据引用
- 差异总结
- 修改建议

AI 不做以下事情：

- 自动补全正式业务事实
- 自动生成正式 description 并保存
- 自动决定 report type、role、parameter 含义
- 自动修改配置

原则：

**AI 可以建议，不能代替事实来源。**

## 5. V1 Scope

V1 必做：

- 元数据导入
- 元数据解析
- 标准化存储
- 规则校验
- 问题确认与修复
- 报表列表/详情查看
- 参数查看
- 配置查看
- 角色查看
- 报表对比
- 版本对比
- Chat/RAG 查询
- 证据回显
- 元数据包导出
- 审计日志

V1 不做：

- 报表执行引擎
- 报表生成
- 邮件推送
- 调度中心
- 模板管理系统
- 工作流审批
- 多智能体自治系统
- 自定义规则平台
- 自动生成正式 description

## 6. 核心业务对象

- Report
- Column
- Parameter
- Role
- ReportConfig
- ReportUiSettings
- ImportJob
- ValidationResult
- Finding
- ChangeLog
- VersionSnapshot
- ChatSession
- Citation
- ExportPackage

## 7. 页面边界

建议页面：

- Dashboard
- Reports
- Import
- Governance
- Compare
- Query
- Logs

不新增页面：

- 调度中心
- 邮件中心
- 模板设计器
- 数据执行控制台

## 8. 一句话边界

系统负责：

**采集、治理、检索、解释、对比、导出报表元数据。**

系统不负责：

**执行、调度、推送、审批、生成正式业务内容。**
